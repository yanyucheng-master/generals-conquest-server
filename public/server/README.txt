   《将领：征服》联机对战服务器 - 本地运行指南
═══════════════════════════════════════════════════

【前置条件】
  1. 安装 Node.js (版本 18+) 
     下载地址: https://nodejs.org/  选 LTS 版本
  2. 安装完成后，确认 node 命令可用:
     node --version


【方式一：一键启动 (推荐)】

  1. 双击运行 start.bat
  2. 首次运行会自动安装依赖
  3. 看到服务器启动信息后即可使用


【方式二：手动命令行启动】

  1. 打开命令提示符 (CMD) 或 PowerShell
  2. cd 到本目录 (server 文件夹)
  3. 安装依赖:  npm install ws
  4. 启动服务:  node index.cjs


【验证服务器是否运行】

  在浏览器中打开:
    http://localhost:3001

  看到 {"status":"ok"} 表示成功


【联机对战使用方法】

  1. 启动服务器 (上面两种方式任选)
  2. 打开游戏网页
  3. 点击"联机对战" → "创建房间"
  4. 复制房间ID或邀请链接发给好友
  5. 好友点击"联机对战" → 输入房间ID → "加入"
  6. 双方各自选择阵营 → 对战开始!


【在同一台电脑上测试】

  1. 启动服务器
  2. 浏览器标签页A: 打开游戏 → 联机对战 → 创建房间
  3. 浏览器标签页B: 打开同一网页 → 联机对战 → 输入房间ID → 加入
  4. 双方选阵营后即可对战


【局域网对战 (两人在同一WiFi下)】

  1. 主机 (运行服务器的电脑):
      - 启动服务器
      - 打开游戏 → 创建房间 → 复制房间ID
  
  2. 客机 (另一台电脑):
      - 打开同一游戏网页
      - 联机对战 → 输入房间ID → 加入
  
  注意: 需要修改前端代码中的 WebSocket 地址为局域网IP
        (具体方法见下方"进阶配置")


【常见问题】

  Q: 提示 "无法连接到联机服务器"
  A: 请先确认服务器已启动 (http://localhost:3001 能访问)

  Q: 防火墙提示
  A: Windows 防火墙弹出提示时，选择"允许访问"

  Q: 端口被占用
  A: 修改环境变量: set WS_PORT=3002 后重新启动


【进阶配置 - 修改WebSocket连接地址】

  如果你需要让局域网内的其他电脑连接，
  需要修改游戏前端代码中的 WebSocket 地址。

  编辑文件: src/hooks/useMultiplayer.ts
  找到:     const WS_URL = ...
  修改为你的局域网IP，例如:
    const WS_URL = 'ws://192.168.1.5:3001';

  然后重新构建: npm run build
  重新部署即可


【技术支持】

  服务器端口: 3001
  日志文件:   控制台实时输出
  停止服务器: 按 Ctrl+C
