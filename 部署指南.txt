========================================
  《将领：征服》公网联机 — 部署总览
========================================

你需要在两个平台分别部署「前端」和「联机服」，
两个都更新后，联机才完整可用。

┌─────────────┬──────────────────────────────────────────────────┐
│ 平台        │ 作用                                             │
├─────────────┼──────────────────────────────────────────────────┤
│ Netlify     │ 游戏网页（玩家打开的网址）                       │
│ Render      │ WebSocket 联机服务器（房间、对战同步）           │
└─────────────┴──────────────────────────────────────────────────┘

当前配置地址：
  前端：https://general-conquest.netlify.app
  联机：wss://yyc-generals-conquest-server-ws.onrender.com

========================================
一、Netlify — 上传哪些文件？
========================================

【上传目录】app/netlify-upload/  （或 app/dist/，内容相同）

【包含文件】
  netlify-upload/
    index.html
    assets/
      index-E5-ATHW4.css
      index-DwyOjQ_K.js

【操作】Netlify → Deploys → 拖拽 netlify-upload 文件夹

【详细说明】见 netlify-upload/上传说明.txt

========================================
二、Render — 上传哪些文件？
========================================

【上传目录】app/render-upload/

【包含文件】
  render-upload/
    index.cjs          ← 服务器主程序
    package.json       ← 只依赖 ws，启动 node index.cjs
    render.yaml        ← 配置参考
    render-server.zip  ← 打包好的 zip（可选）

【操作】
  - GitHub 推送：覆盖 app/server/ 下同名文件，Render 自动部署
  - 或 Render 控制台 Manual Deploy

【Render 关键设置】
  Root Directory : server
  Build Command  : npm install
  Start Command  : npm start

【详细说明】见 render-upload/上传说明.txt

========================================
三、本地改代码后的标准流程
========================================

1. 改前端（src/ 下）
   → cd app
   → npm run build
   → 上传 netlify-upload/ 到 Netlify

2. 改联机服（server/index.cjs）
   → 复制到 render-upload/ 和 server/
   → 部署 Render（Git push 或 Manual Deploy）

3. 若改了 Render 域名
   → 修改 app/.env.production 里的 VITE_WS_URL
   → npm run build
   → 再部署 Netlify

========================================
四、只改了一边会怎样？
========================================

  只更新 Netlify → 可能连不上新服务器，或 UI 是旧的
  只更新 Render   → 前端连旧地址，或缺少新消息类型导致不同步
  → 联机相关改动建议两边一起部署

========================================
五、局域网测试（不上传也可以）
========================================

  1. 运行 start-local.bat 或：
     node server/index.cjs
     npm run dev
  2. 浏览器打开 http://localhost:5173
  3. 联机选「局域网」，同一 WiFi 下对战
