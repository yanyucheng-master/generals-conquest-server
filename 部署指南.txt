========================================
  《将领：征服》公网联机 — 部署总览
========================================

你需要在两个平台分别部署「前端」和「联机服」，
两个都更新后，联机才完整可用。

┌─────────────┬──────────────────────────────────────────────────┐
│ 平台        │ 作用                                             │
├─────────────┼──────────────────────────────────────────────────┤
│ Netlify     │ 游戏网页（玩家打开的网址）                       │
│ Render      │ WebSocket 联机服务器（房间、对战同步）           │
└─────────────┴──────────────────────────────────────────────────┘

当前配置地址：
  前端：https://general-conquest.netlify.app
  联机：wss://yyc-generals-conquest-server-ws.onrender.com

GitHub 仓库：https://github.com/yanyucheng-master/generals-conquest-server

========================================
一、Netlify — 上传哪些文件？
========================================

【上传目录】netlify-upload/

【操作】
  1. npm run build
  2. 将 dist/ 内容覆盖到 netlify-upload/
  3. Netlify → Deploys → 拖拽 netlify-upload 文件夹

【详细说明】见 netlify-upload/上传说明.txt

========================================
二、Render — 联机服
========================================

【源码目录】server/

【操作】
  1. 修改 server/index.cjs
  2. 在上级目录运行 push-github.ps1 推送到 GitHub
  3. Render 自动部署（或 Manual Deploy）

【Render 关键设置】
  Root Directory : server
  Build Command  : npm install
  Start Command  : npm start

========================================
三、本地改代码后的标准流程
========================================

1. 改前端（src/ 下）
   → npm run build
   → 覆盖 netlify-upload/ → 上传 Netlify

2. 改联机服（server/index.cjs）
   → 运行 push-github.ps1 → Render 自动部署

3. 若改了 Render 域名
   → 修改 .env.production 里的 VITE_WS_URL
   → npm run build → 再部署 Netlify

========================================
四、只改了一边会怎样？
========================================

  只更新 Netlify → 可能连不上新服务器，或 UI 是旧的
  只更新 Render   → 前端连旧地址，或缺少新消息类型导致不同步
  → 联机相关改动建议两边一起部署

========================================
五、局域网测试（不上传也可以）
========================================

  1. 运行 start-local.bat 或：
     node server/index.cjs
     npm run dev
  2. 浏览器打开 http://localhost:5173
  3. 联机选「局域网」，同一 WiFi 下对战
